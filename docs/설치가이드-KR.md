# 칼퇴타이머 v2.1.0 — 설치 가이드

> English version: `설치가이드-INSTALL-GUIDE.md`

flex.team 출근 기록을 읽어 칼퇴까지 남은 시간을 세어 주는 메뉴 바 / 트레이
타이머입니다. 점심 카운트다운, 주간 초과근무 집계, 퇴근 시각이 다가오면
색으로 알려 주는 기능이 들어 있습니다.

아래에서 사용하는 OS를 골라 주세요. 어느 쪽이든 앱 안에서 평소 쓰는 Flex
계정으로 한 번 로그인하면 됩니다. flex.team 외의 어디로도 정보가 전송되지
않습니다.

---

## 달라진 점

**v2.1.0 — 한국어 메뉴, 그리고 더 또렷해진 링**

- **메뉴가 한국어가 되었습니다.** 남은 시간, 퇴근 예정, 출근, 주간 초과근무,
  그리고 주간 막대의 월~금까지 바뀌었습니다. 아직 영어로 남은 한 줄은 단축
  근무일 안내(`Target 6:00 · family day`)이며, 리눅스 트레이와 같은 문구를
  씁니다.
- **링이 옆에 표시된 시간을 따라갑니다.** 오전에는 점심까지, 휴식 중에는 업무
  재개까지, 오후에는 퇴근까지 채워집니다. 링이 가득 차면 옆의 숫자가 0:00 이
  되었다는 뜻입니다. 예전에는 하루 전체를 기준으로 채워져서, "점심까지 10분"
  인데도 링은 거의 비어 있었습니다. 색상은 지금도 하루 전체를 따라 변하므로
  오전은 오전처럼 보입니다.
- **주간 막대가 그날 목표 시간까지 꽉 찹니다.** 하지 않을 수도 있는 초과근무를
  위해 오른쪽을 비워 두지 않습니다. 막대가 가득 차면 그날 목표를 채웠다는
  뜻입니다. 초과근무가 생기면 다섯 줄의 기준이 함께 늘어나 서로 비교할 수
  있습니다.
- **메뉴가 한결 조용해졌습니다.** 남은 시간을 큰 글씨로 먼저 보여 주고, 아직
  일하지 않은 날은 뒤로 물러납니다. 마지막 동기화 시각은 재동기화 버튼 옆으로
  옮겼고, 라벨 스타일은 두 줄에서 한 줄이 되었습니다.
- **링이 조금 두꺼워졌습니다.** 메뉴 바 크기에서 색이 더 잘 보이도록 선을 조금
  굵게 했습니다.

**v2.0.2 — 화면 표시**

- **링 색상이 진해졌습니다.** 근무 시간 동안 표시되는 진행 색상이 메뉴 바
  크기에서 너무 연하게 보였습니다. 특히 한낮의 초록색이 그랬습니다. 색상
  계열은 그대로 두고 채도만 높였습니다.

**v2.0.1 — 버그 수정**

- **시간 단위 휴가가 이제 반영됩니다.** 승인이 필요 없는 정책으로 신청한 시간 단위 휴가가 반영되지
  않아, 그날의 목표 시간이 줄지 않고 `Leave at` 이 실제보다 늦게 표시되던
  문제를 고쳤습니다. 이제 다른 휴가와 똑같이 목표 시간을 줄입니다. 아직 승인
  대기 중인 휴가는 계속 반영되지 않습니다.

**v2.0 — 새 기능**

- **메뉴 바 라벨을 새로 그렸습니다.** 남은 시간이 아이콘을 둘러싸며 닫히는
  *링(Ring)*, 또는 라벨 뒤를 채우는 *트랙(Track)* 으로 표시됩니다. 하루가
  얼마나 지났는지 한눈에 보입니다. 메뉴의 **라벨 스타일** 에서 고를 수 있습니다.
- **주간 막대.** 팝오버에 월~금 하루당 한 줄씩 표시되고, 각 막대가 그날의
  목표 시간에 대한 초과근무를 따로 보여 줍니다.
- **단축 근무일 반영.** 승인된 휴가와 가족의 날(매월 마지막 금요일)은 그날의
  목표 시간을 줄입니다. 줄어든 이유는 `Leave at` 아래 설명으로 표시됩니다.
- **주말 정지.** 토요일과 일요일에는 `주말!` 로 표시되며 시간을 세지 않습니다.
  주말은 초과근무로 잡히지 않습니다.
- 경고 색이 따로 맞춘 색이 아니라 시스템 경고 색을 따라갑니다. 그래서 포커스가
  없는 화면의 메뉴 바에서도 잘 보입니다.

## macOS — `칼퇴타이머-v2.1.0.zip`

**macOS 26 이상**, **Apple Silicon**(M1 이상)이 필요합니다. 이 빌드는
arm64 전용이라 인텔 맥에서는 실행되지 않습니다.

1. 압축을 풀고 **칼퇴타이머.app** 을 **응용 프로그램**(/Applications) 폴더로
   옮깁니다.
2. 서명은 되어 있지만 Apple 공증(notarization)을 받지 않은 앱이라 macOS가
   격리(quarantine) 표시를 붙입니다. 아래 명령으로 한 번만 풀어 주세요.
   (우클릭 → 열기 는 현재 macOS 버전에서 통하지 않습니다. 터미널을 쓰세요.)

    ```
    xattr -dr com.apple.quarantine /Applications/칼퇴타이머.app
    ```

3. 앱을 실행합니다. 메뉴 바에 타이머 아이콘이 생깁니다(Dock 아이콘은 없습니다).
4. 아이콘을 클릭 → **Sign in to Flex…** 를 눌러 Flex 계정으로 로그인합니다.
5. macOS가 키체인 접근을 허용할지 물어보면 **항상 허용** 을 선택하세요. Flex
   세션이 저장되는 곳입니다. 모든 빌드를 같은 인증서로 서명하기 때문에 이
   질문은 처음 한 번만 나옵니다.
6. 첫 실행 때 로그인 항목에 자동으로 등록됩니다(macOS가 한 번 알림을 띄웁니다).
   따로 할 일은 없습니다. 자동 실행을 원하지 않으면 시스템 설정 → 일반 →
   로그인 항목 에서 끄면 됩니다.

**v1.x 에서 업그레이드하는 경우** 먼저 기존 앱을 종료하고(메뉴 바 아이콘 →
Quit), /Applications 에서 교체한 뒤 위의 `xattr` 명령을 다시 실행하세요.
아주 초기 버전을 `FlexTimer.app` 이름으로 설치해 두었다면 그것도 지워 주세요.

```
rm -rf /Applications/FlexTimer.app
```

저장된 Flex 세션은 그대로 유지되므로 다시 로그인할 필요는 없습니다.

## Linux (Ubuntu / Fedora KDE) — `kaltoe-timer-linux-x86_64.tar.gz`

Ubuntu 22.04 이상(GNOME) 또는 Fedora(KDE Plasma), x86_64(인텔/AMD)가
필요합니다. ARM은 지원하지 않습니다.

1. 시스템 의존 패키지를 설치합니다(최초 1회):

    Ubuntu:

    ```
    sudo apt install python3-gi python3-gi-cairo gir1.2-ayatanaappindicator3-0.1 \
                     gir1.2-webkit2-4.1 libnotify-bin
    ```

    Fedora:

    ```
    sudo dnf install python3-gobject python3-cairo gtk3 gobject-introspection \
                     libayatana-appindicator-gtk3 webkit2gtk4.1 libnotify
    ```

2. 압축을 풀고 설치합니다:

    ```
    tar xzf kaltoe-timer-linux-x86_64.tar.gz
    cd kaltoe-timer-linux
    ./install.sh
    ```

    `~/.local/share/kaltoe-timer/` 에 설치되고 자동 시작에 등록됩니다. 이
    단계에는 sudo가 필요하지 않습니다. 업그레이드도 같은 명령이며, 기존 설치를
    덮어쓰면서 세션은 유지합니다.

3. 바로 실행합니다(또는 로그아웃 후 다시 로그인):

    ```
    ~/.local/share/kaltoe-timer/kaltoe-tray.py &
    ```

4. 트레이 아이콘 → **Sign in to Flex…** 로 로그인합니다. 세션은
   `~/.config/kaltoe-timer/session.json` 에 본인만 읽을 수 있게 저장됩니다.
5. 시스템 시간대가 올바른지 확인하세요(`timedatectl`). 모든 시각은 시스템
   시계를 따릅니다.

각 단계의 의미, 삭제 방법, 문제 해결은 tarball 안의 `README-linux.md` 에 더
자세히 적혀 있습니다.

KDE에서는 남은 시간이 트레이 아이콘 안에 직접 그려집니다. 리눅스 트레이는
`BREAK` / `OT` 같은 영어 접두어를 그대로 씁니다. 거기서는 접두어를 대신할
아이콘이 없기 때문입니다.

## 화면에 표시되는 내용

라벨은 아이콘과 숫자를 함께 보여 주고, 하루가 지날수록 채워집니다.

| 표시 | 의미 |
|---|---|
| 수면(zzz) 아이콘, 숫자 없음 | 로그아웃 상태 — 메뉴에서 로그인하세요 |
| `--:--` | 로그인은 했지만 아직 출근 기록이 없음 |
| `주말!` + 파라솔 | 주말 — 타이머가 멈춰 있음 |
| `1:20` + 포크 | 점심 시작(11:20)까지 남은 시간 |
| `0:45` + 컵 | 점심 시간 — 12:30까지 남은 시간 |
| `2:34` + 타이머 | 퇴근 시각(출근 + 목표 시간)까지 남은 시간 |
| `0:24` + 걷는 사람 | 퇴근까지 30분 이하 |
| `자유!` | 방금 퇴근 시각에 도달 |
| `+1:05` + 불꽃 | 퇴근 시각 초과 — 오늘의 초과근무가 올라가는 중 |
| `+0:30` + 체크 | 퇴근 완료 — 목표 대비 오늘의 최종 기록 |

색도 같은 흐름을 따릅니다. 그날 목표 안에 있으면 강조 색, 목표를 넘기면
**주황색**, 주간 초과근무 상한에 닿았거나 퇴근까지 10분 이내면 **빨간색**
입니다. 빨간색이면 이제 퇴근하세요!

아이콘을 클릭하면 전체 팝오버가 열립니다. `Leave at`(퇴근 시각), 오늘의 기록,
주간 막대를 볼 수 있습니다. Flex 세션이 만료되면(보통 몇 주에 한 번) 알림이
오니 메뉴에서 다시 로그인하면 됩니다.

## 문제 해결

**"칼퇴타이머을(를) 열 수 없습니다" 또는 `open` 실행 시 `-10810` 오류**

앱 자체는 정상입니다. macOS가 예전 복사본을 찾고 있어서 생기는 문제입니다.
이전 버전이 등록된 상태로 교체되었거나, 휴지통에 아직 남아 있을 때 발생합니다.
어떤 번들이 이 앱 ID를 쓰고 있는지 확인한 뒤, 올바른 것을 다시 등록하세요:

```
mdfind "kMDItemCFBundleIdentifier == 'com.perso.flextimer'"
/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister -f /Applications/칼퇴타이머.app
open /Applications/칼퇴타이머.app
```

첫 번째 명령의 결과에 `/Applications/칼퇴타이머.app` 외에 다른 것이 있으면
— 예전 `FlexTimer.app`, 다운로드 폴더의 복사본, 휴지통에 있는 것 등 — 지우고
휴지통을 비운 다음 `lsregister` 줄을 다시 실행하세요.

**앱 문제인지 macOS 문제인지 구분하기**

실행 파일을 직접 실행해 보세요. macOS의 실행 처리 과정을 건너뜁니다:

```
/Applications/칼퇴타이머.app/Contents/MacOS/FlexTimer
```

메뉴 바 아이콘이 나타나면 앱은 정상이고 위의 등록 문제입니다. 대신
`Bad CPU type` 이 나오면 인텔 맥이라서 유니버설 빌드가 필요합니다 —
Jerome에게 문의하세요.
